INKY VIBES — LATEST WEBSITE

1. Unzip this package.
2. Upload ALL files together to your GitHub repository root (the same folder as index.html).
3. Replace files with the same names and commit your changes.
4. Wait for GitHub Pages to finish updating, then refresh your site.

All images are included beside index.html. No assets folder is needed.
The booking form uses the supplied external Flatpickr scripts, logo URL and Google Apps Script endpoint, so it needs an internet connection.
